Вход для владельца

Введите код доступа, который вам выдал разработчик сайта. На этом устройстве он запомнится, и повторно вводить его не придётся.

Как получить код доступа (для разработчика)
  1. Войдите на github.com под аккаунтом, которому принадлежит репозиторий сайта.
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → ribay-steak-house.
  4. Permissions → Repository permissions → Contents: Read and write (больше ничего не нужно).
  5. Срок действия — до 1 года. Скопируйте код (github_pat_…) и передайте владельцу лично.

Код — как пароль. Если он утёк, отзовите его в тех же настройках GitHub и выдайте новый.

Меню

Меняйте цены и названия прямо в списке. Внизу появится кнопка «Сохранить на сайте» — после неё изменения видны посетителям через 1–2 минуты.
